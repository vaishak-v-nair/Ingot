# Design truth — Ingot guidance video

Distilled from the site's DESIGN.md; where this file is silent, that file decides.

## Concept angle

An assay certificate that learned to speak: the video is a paper document whose sections
settle in and stamp themselves, filmed straight-on. No camera tricks the page itself could
not survive.

## Palette (light — the site's paper, verbatim)

- paper `#fbfaf7` — the ground, every scene
- ink `#16150f` — primary text
- dim `#6d6a5c` — secondary text, captions
- line `#ddd9cc` — hairline rules
- gold `#9a6a00` — kickers, the stamp; a mark, never a fill
- hot `#ff9d1f` — the highlight sweep behind matched words (26–35% over paper)
- ember `#d2451e` — numerals of the numbered record, the one warning tone

## Type

- Display: Instrument Serif 400 (assets/fonts/instrument-serif-400.woff2). No bold exists;
  never ask for weight above 400. letter-spacing 0; only >90px headlines carry −.015em.
- Evidence/labels: JetBrains Mono 400 (assets/fonts/jetbrains-mono-400.woff2), uppercase
  kickers at .2em tracking.
- Body/captions: system sans, dim.

## Layout grammar

- Ruled records, never cards: a 2px ink rule opens a record, a hairline closes it,
  cells divide with 1px line rules. No border-radius boxes except nothing — none.
- Kickers: mono, gold, uppercase, preceded by a 1.9rem gold stroke.
- One focal element per scene; edge anchors are the rules themselves.
- Background layer: paper with a faint 7% hot radial wash at top (the crucible), plus
  ghost mono glyphs at ≤5% opacity drifting very slowly — the only ambient motion.

## Motion doctrine (the site's, applied to film)

Motion that settles, never bounces: ease-out entrances, one highlight sweep per matched
passage (the stamp striking), counters converge on exact values. Nothing loops except a
breathing status dot. No parallax, no spin, no elastic overshoot beyond a whisper.
